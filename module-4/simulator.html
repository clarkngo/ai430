What this teaches

  • Removing a tool beats asking nicely. With least privilege, the agent can't read another customer's order however it's asked, because no tool will do it.
  • Marking reduces injection; it doesn't end it. Retrieved text marked as data is followed less often, not never. That's why the action check sits behind it.
  • No single layer stops everything. Each one covers different attacks, and the suite shows which.
  • Something always gets through. Five $20 credits each pass a $25 limit. A residual risk you can name is part of a strong red-team report.
  • Check the caller before the request. An agent receiving A2A tasks verifies who's asking, and for whom, before any model call.
For your Term ProjectWrite your Term Project's autonomy table now: each action your agent can take, and whether it runs on its own, with a limit, or after a person approves. Phase 3's v1.0 is expected to be red-teamed against it.
