# AI 430: MLOps and AgentOps — Interactive Lesson Lab

The public student site for AI 430 (City University of Seattle, School of Technology & Computing). Static HTML, no build step: open `index.html`.

- `start-here/` — accounts (GitHub, Gemini, Hugging Face, Langfuse), tools, AI Use Guide
- `module-1/` … `module-4/` — lesson, HOS guide, Application Challenge and simulator for each two-week module
- `module-5/` — Term Project guide (Weeks 9–10) and a fictional example project
- `reference/` — Concept Companion, Concept Debate example, Starter Code Walkthrough
- `assets/` — shared CSS and JS; `tools/check_site.py` checks links, anchors and basic accessibility

**Planned, not yet built:** the HOS starter templates (`AI430-HOS01`…`04`), the Application Challenge templates (`AI430-AC01`…`04`) and their GitHub Classroom invites. Pages say so where the links will go.

Check the site before publishing:

```bash
python3 tools/check_site.py
```
