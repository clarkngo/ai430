What this teaches

  • CI is cheap and early. A broken feature function stops at the unit tests, in about a minute, before any training or deployment.
  • The gate compares, it doesn't just measure. A candidate passes only if it beats what's deployed, on every number the gate checks.
  • A gate sees only its conditions. With MAE alone, a model three times slower ships. Add latency and the same model is blocked.
  • Masking catches the exact secret, not a transformed one. A reversed token prints in clear text; only a scan of the output catches it.
  • A retrain is just another candidate. The scheduled job produces a model that goes through the same gate as a code change.
