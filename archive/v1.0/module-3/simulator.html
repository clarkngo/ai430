What this teaches

  • Drift is an early warning. The inputs move weeks before MAE does, because the model hasn't yet met enough of the new data to fail on it.
  • A threshold is a decision. Too loose and drift hides; too tight and every week alerts. The right number comes from your own past weeks.
  • A judge is a model, so it can drift too. Only a regular human-graded sample tells you whether the agent changed or the judge did.
  • Retrieval has a price. A bigger top-k finds more of what the answer needs (recall) and more of what it doesn't (precision), and every chunk is prompt tokens.
  • The database changes latency and operations, not relevance. Same embeddings, same chunks: Chroma and Qdrant return nearly the same passages.
